# Project Architecture Designer (PAD)

A lightweight project scaffolding tool designed to quickly generate clean project structures for different languages, frameworks, and architectures.

## About

This project was developed with assistance from ChatGPT to help design the architecture, naming conventions, and automation workflow. The goal is to make project setup faster, more consistent, and easier for developers.

ChatGPT was used as a development assistant for:
- Brainstorming architecture patterns
- Designing folder structures
- Improving naming conventions
- Creating initial scaffolding scripts
- Exploring framework support ideas

The implementation, customization, and direction of the project are maintained by the developer.
